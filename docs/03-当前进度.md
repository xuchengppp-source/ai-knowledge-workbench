## 关键决策

- Obsidian 只读，编译不反向写回。
- GitHub Pages 静态托管，零服务器成本。
- 问题专题库是知识入口而非原文镜像。
- 工作台定位 = 知识放大循环的呈现面，不产生知识。
- 不做 LLM 语义问答；自测 / 打卡 / 学习记录不进入工作台。
- 路线二：知识 + 互动均进 Supabase + Realtime（云端已就绪，本地待接入）。
- 问题专题库个人私有，不做分享。
- 自动化窗口闸门方案（BYHOUR 调度器不可靠 → HOURLY INTERVAL=3 + 时间闸门）。
- 白名单过滤敏感内容。
