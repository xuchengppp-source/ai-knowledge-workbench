# 软件架构

## 1. 总体架构（单向数据流）

```text
Obsidian 知识库（唯一正式来源，只读）
  → generate.js（Node 编译脚本）
  → data.js（轻量索引）+ docs.js（延迟正文）
  → index.html（桌面版）/ mobile.html（移动版）
  → git commit + push → GitHub Pages → 电脑 / 手机浏览器
```

自动化层：`.workbuddy` automation-1785746711958 每 3 小时轮询源指纹，8:00-24:00 窗口内检测到变化即走完整部署 SOP。

云端实时层（路线二）：Supabase 项目 `ai-knowledge-workbench`（Free / ap-southeast-1）承载知识节点与互动状态，前端运行时拉取 + Realtime 订阅。接入信息已存本地 `.env`（SUPABASE_URL / SUPABASE_ANON_KEY，不进 Git）；数据库当前无业务表，表结构、RLS、Realtime publication 待建（见 PRD Q8）。

智能体协作层（2026-08-05 新增）：多智能体任务接力复用 `dashi-taskboard`（本地 SQLite + HTTP API `127.0.0.1:47823` + `taskctl` CLI），各智能体通过极简 skill 接入；任务产出物经评论关联 Obsidian。与 Supabase 状态层职责分离：Supabase 管知识学习状态，Taskboard 管任务接力。详见 `04-智能体协作状态层.md`。

## 2. 模块职责

| 模块 | 职责 |
|---|---|
| `generate.js` | 扫描配置（VAULT / TOPICS / 各目录）、白名单过滤、frontmatter 解析、正文 MD→HTML、链接提取、每日 / 每周 / 专题解析、生成 `data.js` + `docs.js`、注入版本号 |
| `data.js` | 全局索引：生成时间、主题统计、节点清单（path / title / updated / topic / links / desc / wordCount）、周报统计、每日增量、问题专题（约 310KB） |
| `docs.js` | 节点正文 HTML，延迟加载（约 4.9MB，单行 JSON） |
| `index.html` | 桌面版展示与交互，引用 `data.js?v=xxx` |
| `mobile.html` | 移动版学习界面，与桌面共用 `data.js` / `docs.js` |

## 3. 关键机制

- 白名单过滤：`EXCLUDE_PATTERNS` 排除原始资料 / 资料池 / 蒸馏笔记 / 研究问题 / 日志 / 全局记忆 / 备份 / 点文件。
- 主题配置：`TOPICS` 数组驱动三大主线（agent / enterprise / infrastructure），含图标与配色。
- 双向链接：正则解析 `[[wiki]]` 生成 `nodes.links`，节点详情可跳转 / 返回。
- 摘要抽取：取正文首个非空段落，MD 符号清洗后截取 90 字。
- 缓存控制：`updateAssetVersions` 给 index / mobile 注入 `data.js` / `docs.js` 版本号（`v=YYYYMMDDHHmm`）。
- 移动适配：宽度检测自动跳转 `mobile.html`，`?desktop=1` 强制桌面。
- 自动化指纹：VAULT 下 6 个目录全部 `.md` 的 md5 聚合 → `/Users/xucheng/.workbuddy/workbench_deploy_fp.txt`，比对决定是否部署。
- Supabase Realtime（规划）：互动状态（打卡 / 状态 / 实时跟进）实时读写；知识节点可静态缓存优先、Realtime 增量刷新。

## 4. 数据规模（2026-08-04 快照）

- 节点：98（agent 19 / enterprise 73 / infrastructure 6）。
- 每周复盘：82 页、853 处变更。
- 每日增量：8 条 / 3 判断；日报 4 篇；问题专题 3。
- 产物大小：`data.js` 约 310KB / `docs.js` 约 4.9MB。

## 5. 架构风险与演进方向

| 方向 | 现状 | 需要什么 |
|---|---|---|
| 语义问答 | 本地关键词检索（已确认不做 LLM） | 无需后端，保持现状 |
| 云端实时互动 | 已确认路线二；接入信息已存 `.env`，schema 待建 | 建表 + RLS + Realtime publication；`generate.js` 增补同步；前端接入 supabase-js |
| 编译脚本单点 | 依赖本机 Obsidian 路径 | 保持本机运行；如需云端构建需配置源同步 |
| 正文体积 | `docs.js` 4.9MB 全量加载 | 如需优化可改为按需分片加载 |
